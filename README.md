# Zeds

![Zeds cover](docs/cover.webp)

A short Python survival story. Cross downtown with Bob, choose a route to the safe zone, and replay to discover four endings.

- Terminal: `python Zeds.py`
- Graphical storybook: `python Zeds.py --gui`

Use Python 3.10 or newer. The terminal game uses the standard library. The graphical storybook also needs Tkinter, which may be a separate OS package on Linux.

## Original collaboration and refresh

Joshua Serie and Owen Edwards worked on the original 2019 game. Owen's [last recorded commit](https://github.com/jdserie/Zeds/commit/73fd60a5813309808f7f0017109711e800b59292) and Joshua's [final original revision](https://github.com/jdserie/Zeds/commit/e194dd1eec3c33fb9ab07198859d4300b30f1cef) are both dated February 7, 2019.

Joshua directed the later AI-assisted portfolio refresh. It keeps the original routes and outcomes, makes them replayable, and adds a graphical storybook using the same story data.
